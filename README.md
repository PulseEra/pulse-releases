# Pulse Era installers

Official Pulse Era desktop installers. This repository contains published installers and checksums only.

## macOS Apple Silicon

Version: 0.14.2. Requires an Apple Silicon Mac (arm64).

Download: https://github.com/Gegobite/pulse-releases/releases/download/v0.14.2/Pulse-0.14.2-macOS-arm64.dmg

The installer is signed with Developer ID and notarized by Apple. Open the DMG, drag Pulse.app into Applications, then launch it normally. Updates are installed manually.

Website: https://app.pulseera.ai/
Support: info@pulseera.ai

The DMG includes applicable software licenses and notices. Checksums are published alongside each release. Never overwrite a published version's installer; publish a new version for changed contents.
