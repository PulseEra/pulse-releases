# Pulse Era installers

Official Pulse Era desktop installers. This repository contains published installers and checksums only.

## macOS Apple Silicon

Version: 0.14.4. Requires an Apple Silicon Mac (arm64).

Download: https://github.com/PulseEra/pulse-releases/releases/download/v0.14.4/Pulse-0.14.4-macOS-arm64.dmg

The installer is signed with Developer ID and notarized by Apple. Open the DMG, drag Pulse.app into Applications, then launch it normally. Install 0.14.4 once to enable the new updater. Later updates are checked hourly and after wake, downloaded in the background, and installed on quit or restart.

Website: https://app.pulseera.ai/
Support: info@pulseera.ai

The DMG includes applicable software licenses and notices. Checksums are published alongside each release. Never overwrite a published version's installer; publish a new version for changed contents.

## Windows x64

Version: 0.14.4.

Download: https://github.com/PulseEra/pulse-releases/releases/download/v0.14.4/Pulse-0.14.4-Windows-x64.exe

Run the EXE to install Pulse Era for your Windows user account. Run the installer once to upgrade from 0.14.3. Later updates use the built-in background updater. This Windows installer is unsigned; Windows may show an unknown publisher warning. Claude requires Git for Windows with Git Bash: https://git-scm.com/install/windows
